# DjVuBook AudioLab

Локальное приложение macOS для распознавания DjVu/PDF/изображений, импорта и редактирования текста, экспорта Markdown/EPUB и нейросетевой озвучки в MP3.

## Безопасность и данные

Публичный репозиторий содержит исходный код и тесты. OCR-результаты, книги, пользовательские настройки, модели, виртуальные окружения и аудиофайлы сюда не входят. Обработка книг выполняется локально; для Marker и Silero пользователь указывает папки уже установленных библиотек и моделей.

## Зависимости

- macOS и Xcode Command Line Tools (Swift/AppKit).
- Python 3.13 с Tk для вспомогательной GUI-версии и скриптов импорта; Python-код OCR можно тестировать отдельно.
- DjVuLibre, Tesseract и Poppler для соответствующих форматов.
- Marker/Surya и Silero устанавливаются отдельно и не включены в репозиторий; приложение позволяет указать расположение их окружений.

## Сборка приложения

Запустите `./build_macos.sh`. Скрипт создаёт `dist/DjVuBook AudioLab.app` и кладёт рядом необходимые Python-модули. Для запуска переместите приложение вместе с соседними скриптами как одну папку.

Скопируйте модели Tesseract в `models/` либо выполните `Установить.command`. Установщик использует Homebrew и официальную модель tessdata_best.

## Настройка Marker и Silero

В окне приложения выберите каталоги окружений Marker и Silero. Окружение Marker должно содержать `venv/bin/marker_single`; Silero использует `venv/bin/python` и `models/silero-tts/`. Пример пути — `/Volumes/DjVuBookLibraries/DjVuBook-Marker`; укажите фактический каталог через интерфейс.

## Тесты

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют преобразование страниц, порядок колонок, возобновление Marker, EPUB и безопасное сохранение. Они не заменяют проверку на конкретной книге и Mac.
